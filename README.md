# Tekuani-GameplaySystems-UE5
Authors
• Miguel Angel Garcia Elizalde (Gameplay & AI Programmer)
• Carlos Diego Salgado Villanueva (Gameplay & AI Programmer)

This repository contains a focused extraction of core gameplay systems developed for Tekuani, a 2.5D Action RPG built in Unreal Engine 5.
The goal of this repository is to showcase scalable gameplay architecture, combat system design, and player-focused mechanics implemented in C++.

Systems in Development
The following systems are currently being developed as part of Tekuani's gameplay architecture:

Combat System (In Progress)
• Modular combat structure using Actor Components
• Planned implementation of:
- Damage calculation with mitigation
- Stagger system
- Hit detection using collision queries and raycasting

Ability System (GAS Integration)
• Initial setup of Gameplay Ability System (GAS)
• Framework for handling abilities, cooldowns, and player actions
• Designed to be scalable and data-driven

Architecture
• Component-based design (Health, Combat, Ability)
• Use of Interfaces for decoupled systems
• Structured for scalability and maintainability from early development stages

Technical Approach
The systems are built with the following principles:
• Scalability → systems can grow without major refactors
• Modularity → reusable components across player and enemies
• Clarity → readable and maintainable code structure
• Gameplay-first → responsiveness and feel are prioritized

Notes:
• This repository is intended for technical evaluation purposes
• It represents a work-in-progress gameplay architecture, not a full game
• Full project (including assets and additional systems) is available upon request

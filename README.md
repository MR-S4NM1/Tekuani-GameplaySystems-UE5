## Overview

This repository contains a focused extraction of core gameplay systems developed for *Tekuani*, a 2.5D Action RPG built in Unreal Engine 5.

The purpose of this repository is to showcase scalable gameplay architecture, combat system design, and player-focused mechanics implemented in C++.

---

## Systems in Development

The following systems are part of Tekuani’s gameplay architecture:

### Combat System (In Progress)
• Modular combat structure built using Actor Components  
• Designed to support:
- Damage calculation with mitigation  
- Stagger system and interruption mechanics  
- Hit detection using collision queries and raycasting  

---

### Ability System (GAS Integration)
• Initial integration of Unreal Engine Gameplay Ability System (GAS)  
• Framework for:
- Ability execution  
- Cooldowns and resource management  
- Player-driven actions  

• Designed to be scalable and data-driven  

---

## Architecture

The project follows a modular and scalable architecture:

• Component-based design (Health, Combat, Ability)  
• Use of Interfaces to decouple gameplay systems  
• Separation of responsibilities across systems  
• Designed for maintainability and future expansion  

---

## Technical Approach

The systems are built under the following principles:

• Scalability → systems grow without major refactors  
• Modularity → reusable components across player and enemies  
• Clarity → clean, readable, and maintainable code  
• Gameplay-first → responsiveness and game feel are prioritized
